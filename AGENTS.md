# Instructions for AI assistants

This repo is a student portfolio template. A student has asked you to help fill it in.

## What to edit

- **Edit only `content.js`.** Do not change `index.html`, `script.js`, `layout-*.js`, or any `.css` file.
- Keep the structure, field names, comments, quotes and commas exactly as they are. The file is plain JavaScript, so a missing quote or comma breaks the page.
- Escape a double quote inside text as `\"`.

## How to work with the student

1. **Interview them first**, one or two questions at a time: name, what they study, projects (with GitHub links), skills, education, optional work experience or extracurriculars, and what job or co-op they want. Use their answers to write the `tagline` and `mission` in their voice. Keep it short and genuine.
2. **Never invent facts.** Don't make up projects, jobs, grades, dates, links or skills. If you don't have something, ask, or leave the item out. Replace all of Percy Portfolio's sample content (it's a fake placeholder person) with the student's own, or remove it.
3. Replace placeholder links like `your-username` with real ones, or remove those links.
4. Optional sections (`experience`, `extracurriculars`, `skills`) are hidden when set to `[]`. Use that instead of leaving sample content in.
5. Ask which look they want: a `style` (`"classic"`, `"techy"` for a dark terminal look, or `"fancy"`), an `accent` (preset `"coral"`, `"ocean"`, `"grape"`, `"forest"`, `"sunset"`, `"bubblegum"`, or a hex code), a `font` (`"modern"`, `"serif"`, `"rounded"`, `"mono"`), and `mode` (`"auto"`, `"light"`, `"dark"`).
6. **Photo:** it's in `assets/`, and `photo:` holds its path. If you can run commands, resize it to about 600px wide and under 500 KB, and keep a copy of the original. If you can't, tell them to use squoosh.app or Preview.
7. **Privacy:** this site will be public. Don't add phone numbers or home addresses. Check with the student before adding an email.

## Done checklist

- The student has read through the result and agrees it's accurate.
- `content.js` opens without a red error box when `index.html` is loaded.
- The student knows how to commit and push (see README, section 4).
